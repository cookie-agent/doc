    Tools¶

    This page shows each built-in tool exactly as Cookie Agent sends it to the model: its name, its description, and the JSON Schema of its parameters. Provider adapters place these three fields in their own request format but do not rewrite them.

    A tool is sent only when the active agent has an allow or ask rule for the tool's permission. Some tools have further conditions, noted under each tool. MCP and plugin tools are described by their servers and plugins, not here.

    To see which tools a real session sent with its latest request, expand the tools block under the system prompt in the TUI transcript.

    Tool Permission
    read read
    write write
    edit write
    bash bash
    webfetch webfetch
    skill skill
    delegate_subagent delegate
    get_subagent_result delegate
    cancel_subagent delegate
    send_message message
    goal_get read
    goal_update write

    delegate_subagent¶

    delegate_subagent(agent_type: "<subagent id>", background?: boolean, description: string, inherit_context?: boolean, prompt: string, resume_session_id?: string)

    Description sent to the model:

    Delegate a self-contained task to a specialist agent. Foreground (default) blocks until done. background=true returns immediately with a session handle; the result is pushed back automatically as a <subagent_notification>. If you need to wait for completion, tell the user and end your turn; the notification will wake this session. Use get_subagent_result only to read the available result after notification. To continue an existing subagent, pass its resume_session_id (see the handle in its start/completion notice).

    Only when the agent can delegate to at least one subagent at this depth. The agent_type enum lists those subagents; this page shows a placeholder.

    description string yes Short (3-5 words) summary of the task

    get_subagent_result¶

    get_subagent_result(limit?: integer, offset?: integer, session_id: string)

    Description sent to the model:

    Read the current status and latest result of a subagent you delegated. This call returns immediately; it never waits. A background delegation sends a completion notification to this parent session when it ends. Use the handle from the subagent's start or completion notice, e.g. "explore_1a2b3c4d". Only your own subagents are visible.

    Only when the agent can delegate to at least one subagent at this depth.

    limit integer no Default: 2000.

    goal_update¶

    goal_update(items: object[])

    Description sent to the model:

    Replace the current root goal's full checklist. The current active or paused goal is selected when this update executes, even if the goal changed since this run started. The last accepted replacement wins. This cannot change the objective or issue lifecycle commands; a nonempty all-finished checklist completes the goal. Verify evidence directly or through subagents before marking items finished; the root checklist is authoritative over subagent self-reports.

    Only in a root session whose goal is active or paused when the run starts.
