Checks that bytes are a supported media file of the declared mime_type within the attachment size bounds. The result of a tool that returns a media file whole, as read and read_artifact do: a Media display block, and attachment as the result’s attachment, or as the user message after the result where gate (which gate_attachment decided, and which must admit the file) says the model takes its kind only there.
