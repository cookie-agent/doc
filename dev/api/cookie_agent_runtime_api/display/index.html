Module display 

Source
Expand description

What file-changing tools show clients, shared by the coding runtime’s tools and the engine’s memory tools: language labels, file diffs with real line numbers and five lines of context, and fitting a block to the display budget (docs/site/specs/compatibility-v1.md section 12.5).

Structs§

LineChange
One run of changed lines: removed replaced old_start (a 0-based index into the old lines) onward, and added stands at new_start in the new lines. Lines keep their terminators.
Retain
Where a cut block’s complete content is kept: the session’s artifact store, under filename.

Functions§

diff_block
A diff of path from old lines by changes.
fit_block
block sanitized and fit to the display budget. A cut block of an executed call also names its complete content: its DisplayBlock::to_text before the cut, retained as retain says. A preview has no store to retain it in.
fit_executed_block
An executed call’s block fit to the display budget, as the edit and write tools fit theirs: a cut block names its complete content, kept in session’s artifact store as filename.
hunks
The hunks of changes (in order) to a file of old lines: each change with CONTEXT_LINES of context on each side, changes whose context overlaps or touches in one hunk, and 1-based file line numbers. A side with no lines in a hunk starts at the line before it (0 at the top), as a unified diff numbers it.
language_for_path
The language label clients highlight a file of path with: a fenced code block’s name for the extensions this table knows, else the extension itself (lowercase, when it is a plain word).
line_diff_changes
The line changes from old to new, by a line diff that gives up on an optimal result after a second.
raw_lines
The lines of text, each with its line terminator; a trailing newline does not start another line.
replacement_changes
The line changes of replacing each byte range of matches (in order, not overlapping) in text with new. Each replacement covers the whole lines it touches, replacements whose lines overlap are taken together, and lines a replacement leaves as they were at either end are not part of its change.
text_diff
The diff of a text document labelled label changing as change says, built as the edit and write tools build theirs: real line numbers, five unchanged lines on each side of a change, and the label’s language unless language names one.
