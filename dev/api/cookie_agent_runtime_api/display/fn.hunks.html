pub fn hunks(old: &[&str], changes: &[LineChange<'_>]) -> Vec<DiffHunk>
Expand description

The hunks of changes (in order) to a file of old lines: each change with CONTEXT_LINES of context on each side, changes whose context overlaps or touches in one hunk, and 1-based file line numbers. A side with no lines in a hunk starts at the line before it (0 at the top), as a unified diff numbers it.
