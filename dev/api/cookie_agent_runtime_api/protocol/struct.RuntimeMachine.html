Struct RuntimeMachine

pub struct RuntimeMachine {
    pub id: String,
    pub host_name: Option<String>,
}
Expand description

The machine a runtime runs on, as runtime/initialize reports it.

Fields§

§id: String

A stable, opaque ID of the machine, such as crate::paths::machine_id: 1 to RuntimeMachine::MAX_ID_BYTES bytes of printable ASCII. Runtimes that report one ID run on one machine.

§host_name: Option<String>

The machine’s host name, which names a machine the daemon has not seen before; at most RuntimeMachine::MAX_HOST_NAME_BYTES bytes.
