Constants§

AGENTS_CHANGED
runtime → daemon (notification): the ACP agents the runtime hosts changed (since 1.7.0).
AGENT_EXITED
runtime → daemon (notification): an agent’s process exited (since 1.7.0).
AGENT_MCP
Either direction (notification): one MCP JSON-RPC message of a bridge connection (since 1.7.0).
AGENT_MCP_CLOSE
daemon → runtime (notification): close an MCP bridge (since 1.7.0).
AGENT_MCP_CLOSED
runtime → daemon (notification): a bridge connection ended (since 1.7.0).
AGENT_MCP_OPEN
daemon → runtime: open an MCP bridge socket for an agent’s session (since 1.7.0).
AGENT_MESSAGE
Either direction (notification): one ACP JSON-RPC message to or from an agent’s process, unchanged (since 1.7.0).
AGENT_START
daemon → runtime: start an ACP agent’s process (since 1.7.0).
AGENT_STOP
daemon → runtime: stop an ACP agent’s process (since 1.7.0).
CAPABILITY_OPEN
daemon → runtime: open a capability for a workspace; returns the instance’s identity, tools, and skills.
CAPABILITY_TOOLS_CHANGED
runtime → daemon (notification): an instance’s tool list changed.
CONTEXT
daemon → runtime: per-admission context (AGENTS.md).
FS_CLOSE
daemon → runtime: releases a route or a handle; an uncommitted write is removed (since 1.13.0).
FS_COPY
daemon → runtime: copies one prepared route to another on the runtime’s own machine (since 1.13.0).
FS_PREPARE
daemon → runtime: normalizes a path and resolves its route once, for a transfer (since 1.13.0, runtimes that report files).
FS_READ_CHUNK
daemon → runtime: the next bytes of a read handle (since 1.13.0).
FS_READ_OPEN
daemon → runtime: opens a prepared route to read (since 1.13.0).
FS_WRITE_CHUNK
daemon → runtime: the next bytes of a write handle (since 1.13.0).
FS_WRITE_COMMIT
daemon → runtime: puts what a write handle received in place (since 1.13.0).
FS_WRITE_OPEN
daemon → runtime: opens a prepared route to write (since 1.13.0).
INITIALIZE
daemon → runtime: version, identity, and settings; returns the capabilities the runtime offers.
MCP_CHANGED
runtime → daemon (notification): the status of the runtime’s MCP servers changed, or one failed.
MCP_RECONNECT
daemon → runtime: reconnect one MCP server, or retry every failed one.
PING
daemon → runtime: answer at once, with an empty result, while the connection is up (since 1.4.0). The daemon pings a connection it has heard nothing on for a while and drops one that stays silent; any answer counts, so an older runtime’s unknown_method error does too.
PRODUCER_DISCARD
runtime → daemon: discard one of the runtime’s waiting messages.
PRODUCER_RECOVERY_COMPLETE
runtime → daemon: the runtime’s recovery outcome.
PRODUCER_RECOVERY_START
daemon → runtime (notification): producer messaging is open; restore the external work the runtime tracks, then answer with PRODUCER_RECOVERY_COMPLETE.
PRODUCER_REGISTER
runtime → daemon: register a named producer for a session attached to the runtime.
PRODUCER_SEND
runtime → daemon: send a message through a registered producer.
PRODUCER_UNREGISTER
runtime → daemon: close a registration; its messages stay.
RUNTIME_MCP_CHANGED
runtime → daemon (notification): the runtime’s configured MCP servers changed status, or a runtime-scoped one failed (since 1.5.0).
RUNTIME_MCP_RECONNECT
daemon → runtime: reconnect one runtime-scoped MCP server, or retry every failed one (since 1.5.0).
SETTINGS_CHANGED
daemon → runtime (notification): the runtime’s settings changed in the daemon’s configuration (since 1.10.0). The runtime applies them as runtime/initialize would, starting, stopping, or restarting only the MCP servers and ACP agents that changed.
SHELL_ENVIRONMENT
runtime → daemon (notification): how the runtime’s latest capture of the user’s shell environment went (since 1.12.0). Sent after each capture, and once after runtime/initialize when one already ran.
SHELL_ENVIRONMENT_REFRESH
daemon → runtime (notification): capture the user’s shell environment again, as after the configuration was reloaded (since 1.12.0). A runtime whose capture is off ignores it.
SHUTDOWN
daemon → runtime: stop gracefully.
TOOLS_CHANGED
plugin or runtime → daemon (notification): the tools outside any instance changed. A plugin connection has one implicit instance; a runtime declares here the tools of its runtime-scoped MCP servers (since 1.5.0), which tool/prepare without an instance reaches.
TOOL_CANCEL
daemon → runtime (notification): cancel an executing call.
TOOL_DETACHABLE
runtime → daemon (notification): an executing call reached its detach point.
TOOL_EXECUTE
daemon → runtime: execute a prepared call.
TOOL_PREPARE
daemon → runtime: prepare a batch of calls.
TOOL_PROGRESS
runtime → daemon: display and output of an executing call.
TOOL_RELEASE
daemon → runtime (notification): discard a prepared call.
TOOL_REVALIDATE
daemon → runtime: check a prepared call can still run as approved.
