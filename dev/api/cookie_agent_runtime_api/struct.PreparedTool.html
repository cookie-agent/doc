pub struct PreparedTool { /* private fields */ }
Expand description

A prepared call: its approval identity, normalized arguments, and executor.

A provider the host owns states the call’s approval identity itself (Self::new). Every other provider, such as a runtime’s tools or a plugin’s, only declares the call (Self::declared): the host builds its identity from the tool’s permission and resource and from the tool it knows the call goes to, and sets it with Self::identify before anything reads it.
