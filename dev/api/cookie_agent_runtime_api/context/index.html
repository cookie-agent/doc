Source
Expand description

Workspace context a coding runtime contributes at run admission: the AGENTS.md lookup of docs/site/specs/runtimes.md section 8.

The coding runtime runs it on its own machine and answers runtime/context with the result; the daemon runs the same lookup for an in-process coding runtime.

Applies the AGENTS.md lookup to workspace: the preset’s .cookie-agent/agents/<preset>/AGENTS.md, else .cookie-agent/agents/AGENTS.md, then <workspace>/AGENTS.md. Files over max_bytes (at most AGENT_MD_MAX_BYTES) are skipped.
