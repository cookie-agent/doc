Module text_tools 

Source
Expand description

What the file tools and the memory tools share: the numbered, 1-based pages of text that read, memory_read, and read_artifact return, and the wording of their results and errors.

A page is a LineWindow of lines: offset is the 1-based number of its first line and limit how many lines it holds at most. Each line is returned as N: text, numbered from 1, cut after MAX_LINE_BYTES with a ... [line truncated: N more bytes] marker, and the page stops before it outgrows its byte budget. A page that leaves lines out ends with a continuation marker naming the offset to read next (NumberedPage::continuation).
