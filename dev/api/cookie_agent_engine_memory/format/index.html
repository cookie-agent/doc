How memory reads out ages and sizes (docs/site/specs/memory.md section 16.9.4 and 16.9.7): 3 weeks, 5 days, 1.4 KB, 812 bytes. The wording lives in the protocol crate, so the clients show ages and sizes the way the model reads them.

Functions§

age
How long ago then was at now, as memory reads it out (memory spec sections 16.9.4 and 16.9.7): whole units of the largest unit that fits, from minutes to years (7 days a week, 30 a month, 365 a year), such as 3 weeks; less than a minute for anything shorter, a time after now included.
size
A memory’s size for a reader, such as 812 bytes or 1.4 KB: bytes under 1 KB, otherwise KB of 1024 bytes with at most one decimal.
