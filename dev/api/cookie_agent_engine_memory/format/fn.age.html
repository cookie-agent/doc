Function age

pub fn age(then: Timestamp, now: Timestamp) -> String
Expand description

How long ago then was at now, as memory reads it out (memory spec sections 16.9.4 and 16.9.7): whole units of the largest unit that fits, from minutes to years (7 days a week, 30 a month, 365 a year), such as 3 weeks; less than a minute for anything shorter, a time after now included.
