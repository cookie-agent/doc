Module agents 

Source
Expand description

The agent memory files the daemon keeps (docs/site/specs/memory.md section 16.7): one agents/<agent>.md for every agent of the agent registries that is not internal, whose description and two keywords the daemon owns.

MemoryRoot::sync_agents brings the folder in line with the registries under the memory lock: it creates a missing file with an empty body, rewrites the frontmatter of a file whose description or daemon keywords are off (keeping its body and any extra keywords), and removes the file of an agent no registry has any more when the daemon made it and nobody has touched it since. Doing nothing writes nothing and signals nothing.
