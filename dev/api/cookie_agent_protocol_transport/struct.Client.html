pub struct Client { /* private fields */ }
Expand description

A cloneable client handle. Calls and the single ordered delivery stream share one serialized message stream, regardless of transport.

Complete the protocol handshake with hello. A daemon of another client protocol version refuses it with unsupported_protocol, and a daemon whose version this build cannot speak with is refused here. A hello carrying a token is sent from wiping buffers.
