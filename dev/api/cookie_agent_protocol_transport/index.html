Crate cookie_agent_protocol_transport 

Source
Expand description

The cookie-agent client protocol’s connection client (Client), the daemon’s server loop, and the WebSocket transports, over the wire types of cookie_agent_protocol.

It also builds for wasm32-unknown-unknown, as the Client only: the server and the native WebSocket transport are left out there. With the websocket feature a page connects with Client::connect_browser_websocket and authenticates with Client::handshake_with_token.
