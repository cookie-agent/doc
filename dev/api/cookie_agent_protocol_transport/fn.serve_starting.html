serve for a daemon that may still be starting. Until its server is set, the connection answers handshake (with the status, for a client that reads it), daemon.status, and refuses anything else with daemon_starting; an older client’s handshake waits for the server. Once the status changes with the server set, the same connection is served as serve serves one. A daemon whose startup fails tells the connection and closes it.
