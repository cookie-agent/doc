Expand description

One typed unit of tool presentation.

Text fields allow \n and \t as their only control characters; terminal segment text also allows SGR colour sequences. Every line number is a 1-based file line number. full is present only on a truncated block and names its complete content; the omitted_* members count the whole units a cut left out.
