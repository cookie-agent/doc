load
Loads the built-in defaults and the user layer, and discovers user skills. Configuration has no workspace layer: <cwd>/.cookie-agent/config.toml and <cwd>/.cookie-agent/agents/ are never opened. Project skills are found by each coding runtime for its own workspace when it starts.
load_from_tree
Decodes and validates the built-in defaults and the documents of tree exactly as load_from_user_root does for the same files, without touching the disk. Skills are not discovered.
load_from_user_root
Loads the built-in defaults and an explicit user layer root, primarily for composition and adversarial tests. Skills are not discovered.
load_project_skills
Loads the project skills a coding runtime contributes for workspace: each directory from the repository root (the nearest ancestor with .git, else the workspace itself) down to the workspace, in that order.
load_skill_roots
Loads explicit skill roots in low-to-high project precedence order.
load_user_skills
Loads the user skills (~/.agents/skills, then the cookie-agent user root) once for engine construction; the global runtime contributes them. Skill files are intentionally not hot-reloaded.
