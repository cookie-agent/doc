Where a native model’s context window starts: the first record a request on any model reads verbatim since the latest checkpoint, the earlier of its summary’s kept range and what follows its provider window. Under a provider window alone, the latest summary’s range too, or the whole log when there is none, as a model that cannot use the window reads that. None without a checkpoint.

The approval reviewer’s own log has no checkpoints: an epoch’s first turn starts its window at itself, with nothing pinned before it, as it holds what the epoch kept (section 5.5).
