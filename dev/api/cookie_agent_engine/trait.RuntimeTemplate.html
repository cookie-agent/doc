Expand description

A way to start runtime instances: the built-in global and local runtimes and the configured [runtimes.<id>] templates.

fn start<'life0, 'life1, 'async_trait>( &'life0 self, workspace: Option<&'life1 Path>, ) -> Pin<Box<dyn Future<Output = Result<StartedRuntime, String>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait,

Starts one instance. workspace is Some exactly when Self::takes_workspace is true, and is the path a session asked for, exactly as given: the runtime resolves it and reports the canonical workspace. The error is a human-readable reason.
