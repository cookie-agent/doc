Expand description

A way to reach a runtime and open its capabilities: the built-in global and local runtimes and the configured [runtimes.<id>] templates.

fn start<'life0, 'life1, 'life2, 'async_trait>( &'life0 self, capability: &'life1 CapabilityName, workspace: Option<&'life2 Path>, ) -> Pin<Box<dyn Future<Output = Result<StartedRuntime, StartError>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait, 'life2: 'async_trait,

Opens capability for workspace, which is Some exactly when the capability takes one and is the path a session asked for, exactly as given: the runtime resolves it and reports the canonical workspace. One connection serves every instance; a template whose connection dropped connects again. The error says whether the runtime could not be reached or did not open the capability.
