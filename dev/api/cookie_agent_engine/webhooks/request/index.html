Module request

A webhook request as the HTTP layer read it, its body, and the values a filter or a thread key reads (docs/site/specs/webhooks.md sections 5.2, 5.3, 7.1, and 7.4).

Functions§

delivery_id
A request’s delivery ID (section 5.3): the check’s own header, then Idempotency-Key. A value that is empty, longer than MAX_DELIVERY_ID_CHARS, or holds a control character is skipped.
parse_body
Reads request’s body by its media type. A body labelled JSON (or +json) that does not parse reads as text or binary; an unlabelled body that parses as a JSON object or array reads as JSON.
read_value
The value source reads from a request, as a string: a header’s value, or the JSON a pointer names when it is a scalar (a string as itself; a number, boolean, or null as its JSON text). An object, an array, or nothing reads as None.
thread_key
A request’s thread key (section 7.4): the value source reads, unless it is empty, longer than MAX_THREAD_KEY_CHARS, or holds a control character, when the event has none and gets a session of its own.
