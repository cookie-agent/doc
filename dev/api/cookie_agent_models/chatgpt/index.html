Sign in with ChatGPT: OpenAI’s token sharing, which runs models on a ChatGPT plan through the public Responses API.

The sign-in is an OAuth authorization-code flow with PKCE against auth.openai.com. The first sign-in registers a client for the user with the shared dynamic_agent_client ID and keeps the client ID OpenAI issues on the callback. Tokens live in the provider-store directory, outside the provider store itself, so an hourly refresh never recompiles the model runtime; the store holds only the signed-in account.
