Speech to text through the OpenAI-compatible POST /audio/transcriptions API (docs/site/specs/voice-input.md sections 5 and 6).

A TranscriptionTarget is where one backend’s request goes: a base URL and the headers it carries, credentials included. It comes from a configured provider (crate::CompiledModelRuntime::transcription_target) or from an endpoint and auth written for the backend (TranscriptionTarget::endpoint). Credentials never leave this crate in a readable form: the target’s headers are marked sensitive, and it formats without them.
