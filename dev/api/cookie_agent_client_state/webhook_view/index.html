What the web client’s Webhooks view reads from a webhook (docs/site/specs/webhooks-view.md): a row’s target in words, its tags, and its health line (H1); an open webhook’s counters and what happens to its events (H2, H3); the form’s presets, its “one session per” choice, and its filter as conditions (H4).
