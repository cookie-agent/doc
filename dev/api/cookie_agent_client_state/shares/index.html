Share links for clients (docs/site/specs/share-links.md section 7.1): whether a daemon has them, the expiries the user picks from, a link’s address, and whether that address looks reachable only privately.

daemon_has_shares
Whether a daemon of version keeps share links.
looks_private
Whether a link on base probably works only where the daemon’s page can be reached: plain http, a loopback, private, link-local, or Tailscale (CGNAT) address, a .local name, or, when the daemon has no share base of its own (configured false), a .ts.net name, which tailscale serve keeps on the tailnet. It is a hint: a public address cannot be told for certain.
page_base
The address of the web page of the daemon whose client endpoint is client_url: ws→http, wss→https, with the endpoint’s final ws dropped, so ws://127.0.0.1:7419/ws gives http://127.0.0.1:7419/.
share_address
The address of share: its own url, else page_base, the address the client reached the daemon’s page at, before its path.
