Module badges 

Source
Expand description

Where a session runs, as the badges a session row shows (docs/site/specs/projects.md section 9), and the stable colour of a machine. Badges show machines, never runtime IDs, and the global attachment never counts. A session with no other attachment has no badge; one machine shows its badge and the workspaces, as ~/…; several machines show each machine, in attachment order. A root’s badges count its own attachments followed by the ones its subagents brought (SessionMeta::delegated_attachments, client protocol 1.10.0; docs/site/specs/runtime-delegation.md section 5.3). The machine comes from runtimes.list; a runtime of no known machine stands for its own machine, under its runtime ID.
