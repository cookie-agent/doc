The /runtime panel’s rules every client shares: a session’s attachments matched to their instances, the runtimes a new-session draft attaches, what attaching offers and asks for, and the machines view’s rows and changes (machines.*).

Structs§

DraftRuntime
A runtime a new-session draft attaches. Its instance is opened as soon as it joins the draft, so its status, and why it failed, show before the session exists.
RuntimeChoice
One thing the attach step offers: a capability of a runtime, or a runtime that has not said what it offers yet, which attaching connects and takes its only capability of.
RuntimeRow
One attachment row: what the session records and the instance it refers to, when the daemon reports one.
