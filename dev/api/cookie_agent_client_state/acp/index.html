ACP agents in the clients (docs/site/specs/acp-agents.md section 13, phase 4): the agents a runtime hosts in the agent pickers, with their runtime and availability, and the synthetic model they run under; and the agent’s own model and effort, which the clients show and pick as the model and variant (section 15, input and pickers).
