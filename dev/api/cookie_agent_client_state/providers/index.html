The /connect panel’s rules every client shares: a provider row’s state, what it says about the provider’s models and the catalog, the public setup values and credentials a connect sends (credentials are serialized once, from buffers the caller wipes, never kept), and the store-contention policy of provider.connect and provider.disconnect.
