Module webhook 

Source
Expand description

The webhooks every client shows the same way (docs/site/specs/webhooks.md section 14): whether the daemon keeps webhooks, a webhook’s URL and whether it is likely reachable only privately, its title, target, check, state, counts, and what each event did, the label of a thread prompt’s message, and the webhook form as webhooks.create and webhooks.update take it, with the key: value text both clients edit.
