Expand description

The webhook form: what a user types to create or edit a webhook. Every text field reads as the parse_* function of its kind says; a blank one means none, or the daemon’s default.

Fields§

§name: String§prompt: String

Sent with every event; may be blank.

§target: WebhookDraftTarget§delivery: ProducerDeliveryMode

For a session target, or a new-session one with a thread key.

§permission_mode: Option<PermissionMode>

For a new-session target; the daemon’s default when None.

§model: String

For a new-session target, as crate::cron::parse_model_pin reads it.

§agent: String

For a new-session target: the template’s agent.

§thread_key: String

For a new-session target, as parse_value_source reads it.

§thread_prompt: String

For a new-session target: sent once to each session it creates, and again after each compaction.

§verify: String

As parse_verify reads it.

§secret: String

A secret to set with the check; blank to have the daemon make one (when the check is new or changes) or keep the current one.

§filter: String

One parse_condition per line.

§headers: String

Extra header names the model sees, separated by commas or spaces.

§max_per_hour: String

As parse_limit reads it.

§max_concurrent: String

As parse_limit reads it; new-session targets only.

§max_consecutive_failures: String

As parse_limit reads it.
