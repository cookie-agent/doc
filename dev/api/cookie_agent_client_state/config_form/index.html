Module config_form

Expand description

The web client’s Configuration form: config.toml shown as settings.

SECTIONS says which keys the form knows and how to edit them, MANAGED which tables have a panel of their own. ConfigForm::build sorts the keys of a decoded config.toml into those; whatever it does not recognize, or holds a type its field cannot show, becomes an OtherEntry, shown as it is written and changed in the file. The form never needs to know every key: a key missing here only moves to a box.

A change is one config.apply set per key, so the rest of the file and its comments stay as they are.
