pub fn fork_buffered( path: PathBuf, session_id: SessionId, source: &Self, through_seq: u64, capability: WriteCapability, ) -> Result<Arc<Self>, EventLogError>

A buffered log holding source’s records through through_seq under session_id, validated in memory, for a fork whose file is written whole once it is assembled. It writes nothing until Self::mark_written. The damage the source’s load found in that prefix comes along, so records it excused stay excused.

The fork leaves its source’s subagents behind: each delegation record becomes a record_omitted at its sequence, run, and time, so the sequence stays contiguous. The conversation stays as it was: the delegate calls and their results, the links to the children, and the producer messages that brought their reports.

pub fn owned_from_read_only( &self, capability: WriteCapability, ) -> Option<Arc<Self>>

An owned log over the records this read-only log parsed, without reading the file again. None when the parse ignored a torn final record, which an owned open has to cut from the file, or converted an older history format in memory, which the tree’s owner converts on disk. The caller proves the file is unchanged since the parse.

pub fn write_whole(&self, path: &Path) -> Result<LineIndex, EventLogError>

Writes the log whole as the content of the new file at path (a fork, or a buffered session’s first persistence) and syncs it once, returning its layout for Self::mark_written. Every line the log was read from is copied as it was read, only its session_id set to this log’s; the records appended since are serialized. The caller syncs the directory.

pub fn events_after( &self, cursor: Option<u64>, limit: Option<NonZeroU32>, ) -> EventsSubscribeResult

Physical events after cursor, at most limit of them. The page shares the log’s events rather than copying them, and is cut from a shared view without holding the log’s lock.

A limited page also stops before REPLAY_PAGE_MAX_BYTES (4 MiB) of serialized events, since it goes out as one WebSocket frame; it always holds at least one event, so paging makes progress.
