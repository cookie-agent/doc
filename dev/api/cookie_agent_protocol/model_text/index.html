Module model_text 

Source
Expand description

Text the engine adds to a model’s input from what the session log records, rendered here so the clients show the user the same bytes the model reads: the memory snapshot turn, a deferred tools announcement, the marker that stands for an elided tool output, the line a tool-emitted system message starts with, and a loop warning’s start.

Re-exports§

pub use memory_snapshot::snapshot_turn as memory_snapshot_turn;

Modules§

memory_snapshot
The memory snapshot’s text (docs/site/specs/memory.md section 7.4, as sections 16.9.1 and 16.9.7 amend it): the one user turn history assembly renders from the latest memory_loaded, and the turn the clients show for it. The text depends on the event alone, so equal events render equal text: ages are measured to when the snapshot was taken.
