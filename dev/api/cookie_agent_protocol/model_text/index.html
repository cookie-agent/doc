Module model_text 

Source
Expand description

Text the engine adds to a model’s input from what the session log records, rendered here so the clients show the user the same bytes the model reads: the AGENTS.md turn, the memory snapshot turn, the frame around a compaction summary, a deferred tools announcement, a changed instructions announcement, the marker after an interrupted reply, the marker that stands for an elided tool output, the line a tool-emitted system message starts with, and a loop warning’s start.

Modules§

memory_snapshot
The memory snapshot’s text (docs/site/specs/memory.md section 7.4, as sections 16.9.1 and 16.9.7 amend it): the one user turn history assembly renders from the latest memory_loaded, and the turn the clients show for it. The text depends on the event alone, so equal events render equal text: ages are measured to when the snapshot was taken.

Functions§

agent_md_turn
The AGENTS.md turn, the one user turn holding every loaded file, from the latest load of each source in the latest run, in log order: the project’s file first, then each workspace’s (projects spec section 6). A workspace’s file names its attachment when several attachments gave files; a project’s file says where it is from in its source, project:<name>/AGENTS.md. Empty when no source has a file.
attachment_failure_lines
The lines of an attachment_failures notice, each - …, or of one that earlier builds wrote (lines of [attachment not attached] … after TOOL_EMITTED_SYSTEM_USER_MARKER); None for any other text.
attachment_failures
The notice of a reply’s tags that attached nothing, one line of notes each.
deferred_tools_announcement
The user turn a deferred tools announcement renders as in the model’s history (deferred tools spec section 7.2): the groups that became loadable, each with its summary the first time, then those that left. first is whether no earlier announcement since the latest checkpoint added groups; only the first explains tool_search.
escape_xml_attribute

escape_xml_text

framed_compaction_summary
The user turn a compaction summary reaches the model as.
loop_warning
The loop warning at the end of a tool’s output, if it carries one, without the blank line that separates it: what the model read beyond the tool’s own output.
prompt_blocks_announcement
system_reminder
The user turn a changed instructions announcement renders as in the model’s history (stable prefix spec, section 6.3). A block’s text is the system prompt’s own, so it is not escaped. One of the engine’s own notices to the model, such as changed instructions or a goal the user paused, as the model reads it: inside <system-reminder> tags. What other agents and jobs send keeps its own element (<subagent_report>, <agent_message>, …).
tool_output_elision_marker
What the model reads in place of a tool output that left its context for an artifact: the artifact’s ID (the hex SHA-256 of artifact://sha256/<hex>), the output’s size, and how many messages the tool emitted with it, which go with it.
tools_availability_notice
The user turn a tools_availability_announced event renders as (session tool groups spec, section 8.2): tools the round declared that left, on one machine (with where they still are) or everywhere, then those that came back.
without_loop_warning
output without the loop warning at its end, if it carries one.
