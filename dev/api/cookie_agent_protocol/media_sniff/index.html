Module media_sniff 

Source
Expand description

Recognizing media from its content: the format a file starts like, and the structural checks an attachment must pass (image dimensions, PDF structure). Pure byte inspection, shared by the daemon’s tools and the clients, the web client in a browser included.

Structural image validation. The container must parse exactly and the dimensions it declares must stay within bounds; pixel data is never decoded. The dimension, pixel, and frame caps bound what a provider-side decoder allocates, so they stand in for a trial decode.
validate_pdf
Structural PDF validation without parsing the object graph or decompressing streams: a version header, an %%EOF marker near the end, and a final startxref whose offset lands on a classic xref table or a cross-reference stream object. Encrypted documents are rejected because providers refuse them. Structural PDF validation: a header, an %%EOF marker, and a resolvable startxref; encrypted documents are refused.
