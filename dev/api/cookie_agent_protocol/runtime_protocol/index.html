Module runtime_protocol 

Source
Expand description

Wire types of the runtime protocol between the daemon and a runtime, as specified in docs/site/specs/runtimes.md section 9 and documented in docs/site/reference/runtime-protocol.md.

The protocol is JSON-RPC 2.0, one message per frame: a line over stdio or a frame of an in-memory transport. Every message is bounded by MAX_FRAME_BYTES. Both ends send requests: the daemon drives tools, and a runtime reports progress back while a call runs. crate::peer carries the messages.

Every message is information except the requests and notifications a runtime or plugin sends that ask the daemon to act (tool/progress, tool/detachable, and producer/*): information ignores members it does not know and reads an open enum’s unknown value as its documented fallback (docs/site/specs/compatibility-v1.md section 4); the daemon decodes commands with crate::strict::decode_command, which refuses what their schema does not list. Command types also deny unknown fields themselves.
