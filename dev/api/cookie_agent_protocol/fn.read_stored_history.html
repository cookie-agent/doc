pub fn read_stored_history<T>(read: impl FnOnce() -> T) -> T
Expand description

Runs read as a reader of stored history (docs/site/specs/compatibility-v1.md section 8.5): the size caps a writer keeps to are not applied, so a record reads as its writer bounded it. They are a tool result’s output, metadata, and display budget, a model turn’s serialized size, native replay payloads, and a diagnostic’s detail. Every other check runs.
