pub fn editor() -> String
Expand description

The editor to run, which may carry arguments (code --wait): $VISUAL, else $EDITOR, else vi. Windows has no vi: there the default is VS Code, waiting for its tab to close, when code is on PATH, else Notepad, which waits for its window.
