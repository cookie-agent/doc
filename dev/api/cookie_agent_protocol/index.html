Source

cookie-agent client protocol 1.37, plugin and runtime protocols, and session events.

This crate intentionally contains no compatibility aliases or decoders, except the few that keep versionless session event history readable.

It also builds for wasm32-unknown-unknown, as the wire types and the Client only: the server, the stdio peer, paths, and the other native-only parts are left out there. With the websocket feature a page connects with Client::connect_browser_websocket and authenticates with Client::handshake_with_token.
