Derives the glue that makes an enum open.

Tagged enums with data get an OpenTagged impl; read and write them as Open<T>. The known tags come from the enum’s own schema, so they never drift from its serde attributes:

#[derive(serde::Serialize, serde::Deserialize, schemars::JsonSchema)]
#[serde(tag = "type", rename_all = "snake_case")]
enum Shape {
    Circle { radius: u32 },
    Square { side: u32 },
}
open_enum!(tagged Shape, tag = "type");

let future: Open<Shape> =
    serde_json::from_str(r#"{"type":"hexagon","side":2}"#).unwrap();
assert!(future.is_unknown());

Unit enums are declared inside the macro, which adds an Unknown variant read for any value this build does not know (#[serde(other)]) and marks the schema x-open. Unknown is left out of the schema and serializes as "unknown"; writers never send it. The enum must derive Deserialize, Serialize, and JsonSchema, and document what Unknown means where it is read:

open_enum! {
    #[derive(Clone, Copy, Debug, Eq, PartialEq)]
    #[derive(serde::Serialize, serde::Deserialize, schemars::JsonSchema)]
    #[serde(rename_all = "snake_case")]
    pub enum Weather {
        Sunny,
        Rainy,
    }
}
let future: Weather = serde_json::from_str(r#""foggy""#).unwrap();
assert_eq!(future, Weather::Unknown);

A large enum names each variant’s tag as well, so that Open::tag reads it without serializing the value:

#[derive(serde::Serialize, serde::Deserialize, schemars::JsonSchema)]
#[serde(tag = "type", rename_all = "snake_case")]
enum Shape {
    Circle { radius: u32 },
    Square { side: u32 },
}
open_enum!(tagged Shape, tag = "type", {
    Circle => "circle",
    Square => "square",
});

let shape: Open<Shape> = Shape::Square { side: 2 }.into();
assert_eq!(shape.tag(), "square");
