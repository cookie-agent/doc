Module memory_command 

Source
Expand description

cookie memory: list, show, edit, and delete a daemon’s memory files with the memory.* methods, so it works against a remote daemon (docs/site/specs/memory.md section 10). The listing and show give each memory’s stamps and its size against its limit (section 16.9); edit leaves out the stamp lines the daemon owns.
