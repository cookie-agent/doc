Constants§

DAEMON_TOKEN_ENV 🔒
The environment variable a daemon token may come from, which clap reads into the --token arguments.
MALLOC_ARENA_MAX 🔒
The most glibc malloc arenas, where glibc would make up to eight per core: each holds on to what its threads freed. MALLOC_ARENA_MAX overrides it.
MAX_WORKER_THREADS 🔒
The most async runtime worker threads: the daemon waits on models, tools, and clients far more than it computes, and every worker, with the malloc arena it ends up with, costs memory on a many-core machine while more of them only add scheduling overhead. TOKIO_WORKER_THREADS overrides it.
