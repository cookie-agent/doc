MALLOC_ARENA_MAX 🔒
The most glibc malloc arenas, where glibc would make up to eight per core: each holds on to what its threads freed. MALLOC_ARENA_MAX overrides it.
MAX_WORKER_THREADS 🔒
The most async runtime worker threads: the daemon waits on models, tools, and clients far more than it computes, and every worker, with the malloc arena it ends up with, costs memory on a many-core machine while more of them only add scheduling overhead. TOKIO_WORKER_THREADS overrides it.

dial_in 🔒
Dials in to the daemon at daemon as runtime id and serves it, connecting again after every drop or refusal for now with a growing wait, until stopped. A connection that has carried nothing, not even a pong to its keepalive pings, for DIAL_IN_DEAD_AFTER counts as a drop, so one that died without a close is noticed. A refusal for good, such as a configured or reserved ID or a wrong token, ends it with the daemon’s reason.
