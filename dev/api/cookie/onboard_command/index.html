cookie onboard: set up a daemon, local or remote, through its onboarding API (docs/site/specs/default-models-and-onboarding.md section 7, and docs/site/specs/machines-on-demand.md section 2.2): connect a provider when none is, choose default_model, and optionally small_model and utility_model. The daemon fetches its official agents as it finishes; there is no starter kit. It writes nothing itself; the daemon does.
