The /runtime panel’s rules every client shares: a session’s attachments matched to their instances and the MCP servers each hosts, the runtimes a new-session draft attaches, what attaching offers and asks for, and the machines view’s rows and changes (machines.*).

An ACP agent declaration a runtime offers, as the machines views list it (docs/site/specs/runtime-management.md section 4.2).

One thing the attach step offers: a capability of a runtime, or a runtime that has not said what it offers yet, which attaching connects and takes its only capability of.
