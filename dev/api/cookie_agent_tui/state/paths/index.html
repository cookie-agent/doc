Module paths

How clients show paths. The daemon and runtimes store paths canonical and absolute; a client shows a path of a runtime under the home directory that runtime reported (home in runtimes.list), and absolute otherwise.

Structs§

RuntimeHomes
The home directory each runtime reported, by runtime ID, from runtimes.list (client protocol 1.7.0; empty from an older daemon).

Constants§

RUNTIME_HOMES_MINOR
The client protocol minor from which runtimes.list reports each runtime’s home and SessionMeta lists its attachments.

Functions§

daemon_reports_runtime_homes
Whether a daemon whose handshake reported version reports runtime homes and session attachments. Before the handshake nothing is known.
display_path
path as a client shows it, for a runtime whose home directory is home: ~ for the home itself, ~ followed by the rest under it (~/src/app, or ~\src\app for a Windows path), and path unchanged anywhere else, for a runtime that reported no home, and for a home that is a filesystem root.
