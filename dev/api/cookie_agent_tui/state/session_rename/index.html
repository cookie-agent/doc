Module session_rename 

Source
Expand description

Renaming a session (session.rename): the change a client sends for what the user typed, the TUI’s /rename arguments, and the call. Every rename carries a fresh client_rename_id; the daemon answers a repeat of the same ID and change with the session as it is, so a lost reply can be retried. Clients set a title or go back to the generated one (Reset); none of them offers Clear.
