Module model_draft 

Source
Expand description

A session’s model-selection draft, shared with the daemon’s other clients: a pick is published as the session’s selection once it settles, DRAFT_PUBLISH_DELAY after the last change, so cycling through agents or variants publishes only where it stops. A pick another client makes meanwhile wins: the unsent pick yields, and the draft follows the session’s latest selection.

The client owns the clock: it waits the delay itself and then asks whether its publish is still the latest.
