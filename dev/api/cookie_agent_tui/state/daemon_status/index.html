Module daemon_status 

Expand description

What clients say about the daemon’s status (docs/site/specs/daemon-startup.md section 6): starting, a notice for what it is busy with once ready, stopping, and a failed start. Every task reads the same way, whatever it is.

The one-line notice for a daemon that is not simply ready and idle: starting, failed, stopping, or busy with tasks that do not block it. None when there is nothing to say.
