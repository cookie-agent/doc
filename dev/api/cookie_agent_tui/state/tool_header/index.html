Module tool_header

Expand description

How a tool call’s header reads in every client: the icon of its hint and the primary argument shown after its title; and which argument blocks an expanded call shows under it, leaving out what the header already says.

Functions§

flatten_header_argument
Flatten an on-wire primary argument for single-line header display. The wire type is byte-capped only, so control characters reach the client: map each to a space before collapsing whitespace runs.
hint_icon
The icon for a tool hint (spec 12.2). Hints are open labels: one this build does not document, or none, gets the generic icon. The tool’s name is never consulted.
shown_arguments
The argument blocks an expanded call shows: a block whose text is what the header already shows (the primary argument, or the text its title quotes) is left out, and so is a key/value entry whose value is the primary argument, and a key/value block left with no entries. A block that differs, such as a long command the header shortened, stays. The decision reads the presentation only, never the tool’s name.
