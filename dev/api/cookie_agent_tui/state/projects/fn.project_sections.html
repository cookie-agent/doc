pub fn project_sections(

Expand description

The session list as project sections. A section per project, oldest project first: project IDs are UUIDv7s, so their order is the order the projects were created in, and a new project goes last without moving the others. “No project” comes last and holds every root session of no project or of a project that no longer exists. Each section orders its sessions by order_sessions. Delegated sessions are left out.
