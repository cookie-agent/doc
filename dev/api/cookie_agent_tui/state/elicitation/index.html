Module elicitation 

Expand description

Questions an agent asks the user (client protocol 1.25.0; ACP elicitation, docs/site/specs/acp-agents.md section 15): what the clients keep of a question still waiting, the user’s draft answer to a form, and the words both clients show.

A session’s waiting questions come from its elicitation_requested events; elicitation_resolved or the run’s end removes one.
