Modules§

markdown
Markdown kept in a renderer-neutral form: the source text and its pulldown-cmark events, split into top-level blocks and parsed incrementally while text streams in. Each client renders the blocks its own way and may keep what it derives from a settled block in that block’s RendererCache.
model_draft
A session’s model-selection draft, shared with the daemon’s other clients: a pick is published as the session’s selection once it settles, DRAFT_PUBLISH_DELAY after the last change, so cycling through agents or variants publishes only where it stops. A pick another client makes meanwhile wins: the unsent pick yields, and the draft follows the session’s latest selection.
ownership
Whether this connection owns a session it opens. The daemon answers session.resume for a session another cookie process holds with session_owned_elsewhere; such a session is shown as a read-only snapshot, which no live tail keeps current.
permissions
The /permissions table: a session’s effective rules as rows grouped by action, and the rules a new-session draft holds until session.create.
session_actions
Client behaviour around a session that every client shares: the approval queue a list refresh replaces, the permission-mode cycle, and the complete content of a cut display block.
subscriptions
Which sessions a client keeps subscribed, and when it tries again.
uploads
Uploading a file a message attaches (spec 11.6): what the model accepts, and the chunked artifact.upload.* exchange. A client reads the file and sniffs its content itself; this checks and sends the bytes.
