Module model_input 

Source
Expand description

What the engine adds to a model’s input beyond the conversation, as the transcript shows it, so nothing reaches the model unseen: the memory snapshot turn, a changed instructions announcement, the context a subagent inherits from its parent, and the context an ACP agent’s first prompt carries, each a row whose body is the text the model reads; and the notes a tool row gets for what its result sent beyond the tool’s own output (a loop warning, tool-emitted messages, an elision marker).
