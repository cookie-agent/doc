Module transcript_mode 

Expand description

How much of an agent’s work the transcript shows in every client (docs/site/specs/reduced-transcript.md): every thinking block and tool call, or each assistant block’s work folded into one Working… / Worked for row above its reply.

FoldPlan
The reduced mode’s folds of a transcript. A run’s blocks that only background rows came between (an ACP agent’s background command ending, a background call’s report, a diagnostic below the warning level, a producer message not shown yet) are one stretch of work, those rows included; any other row ends it, and blocks of different runs never join. Once the run’s work ends, the stretch’s last block’s trailing text is its reply. Before it, any text but filler shows as the reply does and splits the work around it into folds of their own, the one before it done. A fold with no thinking or tool call shows as in the full mode, and media always shows.
