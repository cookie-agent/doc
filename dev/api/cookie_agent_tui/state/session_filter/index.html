Module session_filter 

Source
Expand description

The session list’s filter (docs/site/specs/session-pins-and-filters.md): how far back the list reaches, and which agents and machines its sessions run on. The date is the list’s window (crate::session_window), which the daemon answers with every pinned, unread, and busy session too; the agents and the machines narrow what the list holds, those sessions included.

in_range
Whether the list keeps session for a range ending at high and starting at low: pinned, unread, and busy sessions whatever their age, as the daemon lists them, and the rest only when last active in it, so that a session announced since (one just created, say) stays out of a range in the past.
machine_options
