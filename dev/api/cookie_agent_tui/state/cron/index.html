Module cron 

Source
Expand description

The cron jobs every client shows the same way (docs/site/specs/cron.md section 12): whether the daemon keeps jobs, a job’s title, its schedule and a plain reading of it, its target, its state, what each fire did, and the job form’s fields as crons.create and crons.update take them.
