Module badges 

Source
Expand description

Where a session runs, as the badges a session row shows (docs/site/specs/projects.md section 9), and the stable colour of a machine or a runtime. The global attachment never counts. A session with no other attachment has a “no workspace” badge; one attachment shows its runtime and its workspace; several on one machine show the machine, then each runtime; several machines show each machine, in attachment order. The machine comes from runtimes.list; a runtime of no known machine stands for its own machine with its runtime badge.
