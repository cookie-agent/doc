Module permissions 

Expand description

The /permissions table: a session’s effective rules as rows grouped by action, and the rules a new-session draft holds until session.create.

Structs§

PermissionRow
One row of the table: an action’s default (*) or one of its patterns, which may be limited to one runtime (bash@labpc).

Constants§

EFFECTS
The effects a rule can have, in the order a segmented control shows them.
