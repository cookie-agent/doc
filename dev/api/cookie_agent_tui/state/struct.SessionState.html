Expand description

Per-session projection of persisted events and live output.

Fields§

§version: u64

Changes whenever the visible projection mutates, for UI cache invalidation.

§generation: u64§last_seq: u64§created_at: Option<Timestamp>

Creation-event time, used as the deterministic sibling-order fallback.

§last_agent_activity: Option<Timestamp>

Latest user submission or delegate/steer tool start in this session.

§active_run: Option<RunId>§cwd_identity: Option<CwdIdentity>§context_tokens: Option<u64>

Total context occupied at the end of the latest committed turn (input_tokens + output_tokens); None when the turn reported no usage, so the bottom bar hides its context segment.

§estimated_cost_usd: Option<f64>

Latest authoritative session usage cost fetched from the engine. None covers both not-yet-fetched and unpriced usage; both hide the bottom-bar segment.

§run_agent: Option<AgentId>

Frozen producing agent of the latest accepted RunStarted.

§creation_agent: Option<Box<AgentSnapshot>>

The complete frozen creation snapshot from SessionCreated, including the exact frozen fallback chain. Delegated draft projections derive only from this, never from live descriptors.

§run_snapshot: Option<Box<AgentSnapshot>>

The complete frozen snapshot of the latest accepted RunStarted.

§model_tools: Option<Arc<[String]>>

Tool names of the latest ModelToolsPublished: what the model was last offered.

§model_selection: SessionModelState§runtime_attachments: RuntimeAttachmentFold

The session’s runtime attachments, folded from its attach and detach events.

§goal: Option<GoalState>§acp: AcpSessionView

What the session’s ACP agent reported: its slash commands and its config options. Empty for a session of a daemon agent.

§transcript: Vec<TranscriptItem>§item_times: HashMap<u64, Timestamp>

Durable insertion time per transcript item id. Cross-session rows such as aggregated descendant warnings merge into a viewed transcript by this time, so mid-conversation breaks render at their chronological position instead of the bottom.

§pending_inputs: VecDeque<PendingInput>

The engine’s pending-input lane for this session, reduced purely from admission/promotion/recall events: steered messages the model has not seen yet. Source of the queue strip between the conversation pane and the composer.

§initial_input_submitted: HashSet<RunId>

Runs whose initial (non-lane) input has already been submitted. Later submissions for the same run are pending-lane promotions.

§user_files: HashMap<u64, Vec<ArtifactRef>>

The files each submitted user message attached, by the message’s seq, for clients that show them.

§voided_inputs: Vec<VoidedInput>

Pending inputs the engine voided at run end (no per-entry events), parked here until the UI restores their text into the composer — user text is never silently lost. Drained by the UI on sight.

§queued_inputs: QueuedInputs

Inputs queued behind the running run, from every client.

§next_transcript_id: u64§next_live_part_id: u64

Ids handed to parts opened by live-only output, which has no durable sequence to derive one from. See LIVE_PART_ID_BASE.

§open_assistant: Option<OpenAssistantProjection>§thinking_durations: HashMap<(u64, u64), Duration>

Elapsed thinking time per sealed thinking part, keyed by (item_id, part_id) and derived from durable event timestamps.

§stream_marks: HashMap<AttemptId, Vec<(StreamedOutputKind, Timestamp)>>

When each unfinished attempt’s streamed parts began, from its durable ModelOutputStarted marks. Its commit times its thinking from these, identically live and on replay, where the deltas themselves are gone.

§event_timestamps: BTreeMap<u64, Timestamp>

Durable event timestamps by sequence, pruned at each committed turn’s input boundary; backs replay-exact generation durations.

§assistant_metrics: HashMap<u64, AssistantTurnMetrics>

Generation metrics per assistant item, accumulated from committed turns, for the subordinate footer row at the end of the block.

§open_run_assistant: Option<RunAssistantProjection>§interrupted_assistant_items: HashSet<u64>

Assistant blocks whose run ended in RunInterrupted; their footer reads … · interrupted.

§attempts: HashMap<AttemptId, AttemptProjection>§pending_attempt: Option<AttemptId>

The latest attempt until its first delta, commit, or abandonment.

§tools: HashMap<ToolCallId, ToolCallState>§background_calls: Vec<BackgroundCall>

The session’s background calls, as the daemon last reported them.

§pending_tool_rows: Vec<PendingToolRow>

Buffered tool rows awaiting their committed placeholder, keyed by the owning turn’s content index so starts/completions cannot reorder.

§turn_tool_index: HashMap<(u64, String), IndexedToolCall>

Durable tool input indexed from committed turn content: (model_turn_seq, model_call_id) → arguments JSON, for expanded rows.

§turn_items: HashMap<u64, u64>

The assistant item owning each committed model-turn sequence.

§replay_context_warnings: HashSet<(RunId, Sha256Digest, ReplayContextTransition)>

User-visible replay compatibility transitions already projected for a run. Durable replay/reconnect and later tool-loop attempts may repeat request diagnostics without creating another logical transition.

§model_turn_warnings: HashSet<(RunId, String)>

Adapter warnings already surfaced for a run. After a model fallback the same reconstruction warnings regenerate on every committed turn; each distinct warning text is shown only once per run.

§goal_revisions: HashMap<GoalId, u64>§producer_messages: HashMap<ProducerMessageId, ProducerMessageProjection>§producer_dedup: HashMap<(ProducerOwner, ProducerIdempotencyKey), ProducerMessageId>§producer_claims: HashMap<u64, ProducerClaimProjection>§terminal_runs: HashSet<RunId>§approvals: Vec<ApprovalState>§agent_md_latest_run: BTreeMap<String, Vec<AgentMdEntry>>

AGENTS.md entries loaded by the latest run and by the run before it, per attachment (events without one count as local). A run loads one event per coding attachment that returned a file. A row appears only when an attachment’s context differs from its previous run’s, so turning AGENTS.md off and back on shows again even when the files are unchanged.
