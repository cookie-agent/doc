Module onboarding 

Source
Expand description

The onboarding rules every client shares (docs/site/specs/default-models-and-onboarding.md section 9, and docs/site/specs/machines-on-demand.md section 2.2): the four steps, which are done, the model lists the pickers show, the variant each picker preselects, the fallback lists a model step builds (docs/site/specs/model-fallback-lists.md section 6), why Finish is disabled, and the summary of a run.
