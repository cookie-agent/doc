Module speech 

Source
Expand description

Voice input on the client side (docs/site/specs/voice-input.md sections 3, 4, and 7): sending a recording to be transcribed, the recorder’s format, and the words a dictation adds to a draft.

Constants§

RECORDER_TYPES
The containers a recorder may make, best first: Opus in WebM (Chrome, Firefox), Opus in Ogg, then MP4 audio (Safari).
WAV_SAMPLE_RATE
The rate a WAV recording is made at: what speech models listen at.

Functions§

add_words
draft with words dictated at its end, a space between them.
cancel
Drops a recording, or abandons its transcription; a recording already gone is no error.
cancelled
Whether error is a cancellation the user asked for, which says nothing.
clock
A recording’s length as the bar shows it, m:ss.
encode_wav
samples (-1 to 1, mono, at rate Hz) as a 16-bit PCM WAV file.
failure_text
What the recording bar says when a transcription fails.
limit_text
The recording limit, if any, the bar shows after the time.
recorder_type
The first of RECORDER_TYPES the browser supports; None leaves the choice to it.
resample
samples at from Hz, at to Hz: each output sample averages the input it covers when going down (a crude low-pass, enough for speech), and interpolates between neighbours when going up.
transcribe
Sends bytes, a recording of media_type, and waits for its words. begun gets the transcription’s ID as soon as it has one, so the caller can cancel it.
