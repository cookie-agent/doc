Module format 

Source
Expand description

Numbers, counts, costs, and times as every client writes them: token counts with thousands separators or in short form, costs in US dollars, shares as percentages, elapsed times, and how long ago something happened.

Each formatter first works out what it shows (which unit, how many decimals, which bracket of time) and then writes it; the tests check the first step, the arithmetic, not the text.
