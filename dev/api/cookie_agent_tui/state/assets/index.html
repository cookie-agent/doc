Assets in clients (docs/site/specs/assets.md): the assets replies show with <attach asset="…"/> (docs/site/specs/message-attachments.md), the links into the web page the TUI prints (section 9), and how the web’s Assets tab sorts out what it lists (section 8.3).

Structs§

AssetFilter
What the Assets tab lists (section 8.3): whose assets, every project’s when project is None, and of which level, both when scope is None. Kind and search narrow it further in the page.
AssetPlace
Where an asset lives, as its row says: its project’s name, or “No project”, and for a session tree’s own asset the tree’s root and its title, when it has one.
