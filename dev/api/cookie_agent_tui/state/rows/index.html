Module rows 

Expand description

How the transcript’s non-message rows read in every client: producer messages (goal control, background-call reports, delegation reports), goals, and the system prompt and tools rows pinned at its top, with the bounds every client shows an opened row’s body within.

Structs§

BoundedText
A body cut to the bounds an opened row shows: its lines, control characters but tabs shown as U+FFFD, and how many lines did not fit.

Constants§

MAX_EXPANDED_BODY_BYTES
The most bytes an opened row shows of its body.
MAX_EXPANDED_BODY_LINES
The most lines an opened row shows of its body (the tools row’s list included).
MAX_SYSTEM_PROMPT_BODY_BYTES
The most bytes the opened system prompt row shows.
MAX_SYSTEM_PROMPT_BODY_LINES
The most lines the opened system prompt row shows.

Functions§

bounded_text
text within max_lines lines and max_bytes bytes: whole lines, then the part of the line the bytes run out in. The lines past the bounds, and a line cut short, count as omitted.

The tools the opened tools row lists: as many as fit MAX_EXPANDED_BODY_BYTES joined with , , as the TUI’s line does, and how many more there are.
display_line_count
How many lines text has, as the collapsed rows count them.

Whether the bar above the composer shows a goal in status: only while it is still being pursued. A completed or cancelled goal stays reachable through the goal details, not the bar.

Orders a session list: the active sessions first, then the rest, each group newest activity first; sessions that tie keep their order. It knows nothing of how a list is grouped, so a client orders each group (each project’s sessions, say) on its own.
