The cookie agent web client: a Leptos page rendered in the browser (client-side), speaking the client protocol through cookie_agent_protocol’s browser transport. scripts/build-web.sh builds it with Trunk; cookie daemon serves the result.

The crate also compiles natively, so the workspace builds without the wasm target; its tests cover the pure logic only.

Modules§

attach
Attaching files in the page: what the model accepts, as an accept attribute, and how far an image must shrink to fit its limits before it is offered downscaled.
browser
The few browser services the page uses: its address, storage, history, the colour scheme, visibility, and installing the page as an app. Everything here is a thin call into web_sys; it compiles on every target but only works in a browser.
commands
The slash commands the page has, with the TUI’s names and aliases. The command menu lists every one, as phones lack a convenient /.
connect
The connect screen’s decisions, independent of the browser (spec 7.2, 7.3): the daemon URL a page fills in from its own address, the token a #token= fragment carries, what a launch starts from, whether to connect without a click, and the hint for a connection refused before its handshake.
connection
Opening the daemon connection from the page, with the tab’s identity.
errors
How the page says what went wrong. A daemon error is drawn from its fields (its message, its hint, and its detail), never from the error’s display text, which already joins the message and the hint: a page that showed that text and then the hint said the hint twice. Each part is sanitized as the protocol’s own display text is.
format
Short forms the page shows where room is tight: a directory’s last component, how long ago something happened, a token count, and a cost.
goal
The root session’s goal: what /goal asks for, and which lifecycle actions the goal bar offers, as the TUI’s bar does.
icons
The page’s icons: Font Awesome Free 6, whose artwork is CC BY 4.0, from the icondata crate. Components show them through leptos_icons; the transcript, which renders to HTML text, inlines the same SVG. Each icon is a static the linker keeps only when the page names it.
install
Installing the page as an app (spec 9), independent of the browser: which offer the page makes from what the browser says about itself.
keys
What a key does in the composer, as in the TUI: Enter steers, Alt+Enter queues, Shift+Enter, Ctrl+Enter, and Ctrl+J insert a newline, Escape cancels, and Up in an empty composer recalls this client’s newest pending or queued message. Also which buttons the composer shows, and how tall its text grows.
layout
Where the page is, independent of the browser: the rail’s views, the Settings sections, which view a slash command opens, the commands the session’s ⋮ menu offers, the history entries browser Back closes, and the press that offers to delete a session row on a touch screen.
render
The transcript as HTML: pure functions from the shared client state to markup the page inserts as is. Everything a model, a tool, or a user wrote is escaped here, so no input can add markup of its own; the only markup is what these functions write. Interactive parts carry data-action attributes, which one click handler on the transcript dispatches.
skills
/skills: which skills a search shows, ranked as the TUI ranks them.
theme
The light or dark theme: the system’s, or the user’s override kept in localStorage.
tree
The subagents nested under their session in the sessions list: which rows a session tree shows, folded where the user folded it, whether the session’s row expands at all (/agent-panel), the title bar’s path to a viewed subagent, and the subagent a delegate call started.
workspace
The connected page’s state and what it does with the daemon: the session list, the viewed session’s projection (the shared reducer), its subscriptions, the composer, approvals, the model draft, the permission mode, and usage. It mirrors the TUI, with the same calls and the same shared client behaviour from cookie_agent_client_state; timers run on the browser’s event loop.
