Module tree 

Source
Expand description

The subagents nested under their session in the sessions list: which rows the open session’s tree shows, collapsed or expanded, the title bar’s path to a viewed subagent, and the subagent a delegate call started.

Only the open session’s row has a tree. Collapsed (the default), it shows the subagents that run, at any depth, with their finished ancestors dimmed so each sits in its place, and the subagent the page shows; with nothing running it shows nothing. Expanded, it shows the whole hierarchy. A click on the open session’s row switches between the two, and the browser remembers the choice per session.
