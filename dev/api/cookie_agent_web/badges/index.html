Module badges 

Source
Expand description

Where a session runs, as its row shows it: the badges of client_state::badges, each machine in its stable hue (the hue-* theme tokens in style/main.css), and the hue’s dot that marks a runtime, in its machine’s colour, in the bottom bar and on the runtime cards.

fit
Fits the badges of line, a one-line flex box: the workspaces shrink first (by their style, down to …), then leave the line; when the machines alone still do not fit, the last ones leave it, whole, for a +N badge whose tooltip names them. A machine’s name is never cut.
