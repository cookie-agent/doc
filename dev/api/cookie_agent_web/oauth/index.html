Module oauth 

Source
Expand description

Signing in to MCP servers from the page (spec): the OAuth redirect is the page itself with ?oauth=callback, the sign-ins this browser started are kept by their state, and a tab the authorization server sends back hands its address to the tab that started the sign-in over a BroadcastChannel, or finishes the sign-in itself.

The rules are plain functions, tested natively; the browser calls at the end of the module only work in a browser.
