Module cards 

Source
Expand description

The new-session runtime cards, independent of the browser: one card per runtime capability that takes a workspace, plus global, grouped by the machine each runtime runs on; which cards a new session selects and at which workspaces; the defaults, the workspace suggestions, the note about tool-name prefixes, and what the browser remembers.

The selection keeps the text the user typed: the daemon and the runtime resolve it (~/… included). Opening a workspace answers its canonical path, which the session is created with.
