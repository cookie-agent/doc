Module connect 

Source
Expand description

The connect screen’s decisions, independent of the browser (spec 7.2, 7.3): the daemon URL a page fills in from its own address, the token a #token= fragment carries, whether to connect without a click, and the hint for a connection refused before its handshake.

Constants§

DAEMON_URL_KEY
The localStorage key of the daemon URL the user last connected to.
EVENT_LEVEL_KEY
The localStorage key of the lowest diagnostic level the transcript shows (/events).
IDENTITY_KEY
The sessionStorage key of this tab’s client identity: each tab is its own client, kept across reloads and reconnects.
SIDEBAR_KEY
The localStorage key of whether a desktop window shows the sessions sidebar: hidden once the user hid it, else shown.
THEME_KEY
The localStorage key of the theme preference.

Functions§

connects_by_itself
Whether the page connects without a click: it has a daemon URL (filled in or remembered) and a token (from the fragment or stored).
daemon_url_for_page
The daemon URL a page at page (its location.href) fills in: the page’s scheme as a WebSocket scheme (http→ws, https→wss), its host and port, and ws in the page’s directory. None for a page that is not served over HTTP, such as a file: page.
fragment_without_token
The fragment left after taking the token out: the other parameters, in their order, or nothing.
refused_before_handshake_hint
What the connect screen says when the daemon closed the connection before its handshake. A browser shows the page no reason, and the usual one is an origin the daemon does not allow, so it names the entry to add.
sidebar_shown
Whether a stored sidebar choice shows the sidebar: every value but hidden, so the sidebar shows until the user hides it.
token_from_fragment
The token a page’s location.hash carries as #token=<token>, among other &-separated parameters; None without a non-empty one.
token_key
The localStorage key of the token stored for the daemon at daemon_url.
