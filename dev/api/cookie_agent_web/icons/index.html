Module icons 

Source
Expand description

The page’s icons: Font Awesome Free 6, whose artwork is CC BY 4.0, from the icondata crate. Components show them through leptos_icons; the transcript, which renders to HTML text, inlines the same SVG. Each icon is a static the linker keeps only when the page names it.

Icons inherit the text colour (currentColor) and are hidden from assistive technology: the button or text beside them carries the name.

row_status
The mark a session’s row shows before its title, if any: a turning circle while it runs, a pause while it is held, a clock while it waits on a producer (an active goal, a background call, a subagent, or an external producer) to start its next run, and a mark when its last run failed or was interrupted. A finished, idle, or cancelled session has none, so its title starts at the row’s edge. Running outranks waiting, which outranks a problem.
