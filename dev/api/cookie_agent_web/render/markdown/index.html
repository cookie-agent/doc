Module markdown 

Source
Expand description

Markdown to HTML from the shared [MarkdownDocument]’s events. Raw HTML in the text is escaped and shown as written, never rendered; links go only where super::safe_link allows and open in a new tab; images are shown as links, so a page never loads a remote image on its own; code blocks carry their language for the highlighter.

Where an <attach …/> tag of a reply stands in its HTML, which the transcript replaces with the attachment’s card, in the tags’ order.
