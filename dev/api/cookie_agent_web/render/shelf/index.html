Module shelf 

Source
Expand description

A run’s shelf as HTML (docs/site/specs/assets.md section 8.1): its assets as cards in one wrapping row, whose widths let them share rows. Images and video are one deck, a page and a document cards that open in the side panel, audio a player, and any other file a chip with a download. Each card is an asset placeholder (data-asset) the page fills in after drawing it (crate::assets), in the way its data-asset-view names. Handles the reply names become chips that open their card.
