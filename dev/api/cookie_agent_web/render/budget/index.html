Module budget 

Source
Expand description

The row budget of a tool’s output, as in the TUI: an expanded call shows its first lines and says how many more there are; a click on that shows up to the larger budget. The budget counts lines as the blocks show them, whatever their kind, and never looks at the tool.

Constants§

ALL_OUTPUT_LINES
Lines it shows once that is clicked.
OUTPUT_LINES
Lines an expanded call shows before “… N more lines (click to expand)”.
