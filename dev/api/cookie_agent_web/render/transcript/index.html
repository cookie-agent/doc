cookie_agent_web::render

Module transcript 

Source
Expand description

A session’s transcript items as HTML, from the shared reducer’s projection. Each item renders on its own, so the page re-renders only the items whose item_key changed; an assistant reply renders part by part (transcript_rows), so a streaming reply draws again only the parts that changed, and its text only its open tail.
