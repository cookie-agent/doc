A session’s transcript items as HTML, from the shared reducer’s projection. Each item renders on its own, so the page re-renders only the items whose item_key changed.

pinned_rows
The rows pinned at the top of the transcript, as the TUI pins them: the system prompt the latest run used (else the one the session was created with), and the tools the latest model request offered. Both start folded, side by side on one compact line; an opened one takes a line of its own with its body under it. They are one item, keyed by its HTML, which changes with what it shows.
