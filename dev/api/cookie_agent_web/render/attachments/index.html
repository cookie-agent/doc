Module attachments 

Source
Expand description

A reply’s attachments as HTML (docs/site/specs/message-attachments.md section 6): each <attach …/> tag of its text, which the Markdown renderer left as a super::markdown::ATTACH_MARKER, becomes a card where it is, and tags next to each other one row of cards whose widths let them share rows. Pictures and video of a row are one deck, a page and a document cards that open in the side panel, audio a player, any other file a chip with a download. Each card is a placeholder (data-asset) the page fills in after drawing it (crate::assets), in the way its data-asset-view names: an asset’s live, an attached file’s from the session’s artifacts. Handles of shown assets the text names become chips that open their card.
