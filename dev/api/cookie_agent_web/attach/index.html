downscale_target
The size an image of width×height and bytes bytes is re-encoded at to fit limits: within the longest side and the pixel count, and, for the byte limit, scaled by the square root of the ratio with some room, since an encoder’s output shrinks with the pixel count. None when it fits as it is.
